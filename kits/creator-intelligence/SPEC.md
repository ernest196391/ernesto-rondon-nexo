# NEXO Creator Intelligence — SPEC

## Entrada
URL pública de canal, perfil o contenido.

## Flujo
prepare → acquire → analyze → result.

## Evidencia mínima
Host, título, meta description y Open Graph del HTML inicial.

## Salida
Cinco hallazgos que separan evidencia, interpretación y acción. No se inventan vistas, frecuencia, outliers, CTR, retención ni transcripciones que no estén conectadas.

## Ejemplo reproducible
Usar una URL pública de YouTube y verificar que la salida reconoce la fuente, extrae señales disponibles y declara explícitamente las métricas ausentes.
