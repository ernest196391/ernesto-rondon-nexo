# NEXO Brand Intelligence — SPEC

## Entrada
URL pública de una persona, marca o negocio.

## Flujo
prepare → acquire → analyze → result.

## Evidencia mínima
Título, meta description, Open Graph, canonical y jerarquía H1 del HTML inicial.

## Salida
Cinco hallazgos que separan evidencia, interpretación y acción. No se emiten conclusiones de identidad visual definitiva sin captura/render o activos aportados.

## Ejemplo reproducible
Usar una web pública de marca y verificar que el resultado explicita qué se observó y qué queda pendiente de evidencia visual.
