# NEXO Commerce Audit — SPEC

## Entrada
URL pública de una tienda.

## Flujo
prepare → acquire → analyze → result.

## Evidencia mínima
Viewport, formularios, enlaces, metadatos, jerarquía H1 y recuento de scripts del HTML inicial.

## Salida
Cinco hallazgos que separan evidencia, interpretación y acción. No se afirma estado de checkout, ventas, Core Web Vitals ni métricas privadas sin fuentes adicionales.

## Ejemplo reproducible
Usar una tienda pública accesible por HTTPS y comprobar que devuelve cinco hallazgos y limitaciones explícitas sin realizar acciones mutantes.
