Los iconos de NEXO tienen una retícula de 24 × 24, trazo de 2 px y remates y uniones redondas, sin relleno. El trazo de los archivos es `#121212` (nexo-tinta), porque un `<img>` no puede cambiar el color de un SVG. Para que el icono tome el color del texto, incrusta el SVG en el código y pon `stroke="currentColor"`.

Nombres: `icono-<función>.svg`. Ejemplos: `icono-vender`, `icono-sin-conexion`, `icono-pregunta` (Pregunta a NEXO). Los estados son `icono-bien`, `icono-aviso`, `icono-error` e `icono-info`.
