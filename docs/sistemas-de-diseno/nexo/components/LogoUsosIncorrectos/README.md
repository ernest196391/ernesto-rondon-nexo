Usos incorrectos del logo de NEXO: doce errores que no se aceptan en ninguna pieza.

1. Deformarlo o cambiar su proporción.
2. Girarlo o inclinarlo.
3. Poner el amarillo sobre blanco o escribir el nombre en amarillo.
4. Usar colores fuera de la paleta.
5. Añadir sombras, degradados, brillos o relieves.
6. Convertirlo en contorno.
7. Cambiar el orden o la posición del símbolo.
8. Poner la palabra del producto en otro color, peso o tamaño.
9. Escribir NEXO con una fuente en lugar de usar el archivo.
10. Invadir el área de protección.
11. Ponerlo sobre fondos con mucho detalle sin una placa sólida de `ink`, `brand` o blanco.
12. Separar el símbolo para usarlo como adorno, patrón o viñeta.
