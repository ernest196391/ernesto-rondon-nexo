# Recursos para videos (biblioteca compartida)

Lo que se reutiliza en todos los videos, para no buscarlo ni pagarlo dos veces. Antes de buscar fuera, mira aquí. Si bajas algo nuevo, guárdalo aquí y apunta de dónde salió.

## Cómo añadir
- **Música:** biblioteca gratuita de Pixabay (pixabay.com/music), sin letra. Nombre del archivo: `<ritmo>-<ánimo>-<bpm>.mp3` (por ejemplo `rapido-alegre-120.mp3`). Apunta abajo el enlace de origen.
- **Iconos:** SVG libres (Lucide, Tabler, Phosphor) o de un tablero público de Pinterest bajado con `gallery-dl <enlace>` (solo los que tengan licencia libre).
- Nada con marca de otra empresa, ni canciones famosas con letra.
