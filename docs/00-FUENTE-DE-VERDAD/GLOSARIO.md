# GLOSARIO — un solo idioma

Si un documento, una pantalla o un chat usa un nombre de la columna "Nombres viejos", **no lo repitas**: usa el oficial.
Se cambian en el código y en las pantallas poco a poco, cuando se toque esa parte; no hace falta una mudanza masiva.

## Marcas y productos

| Nombre oficial | Qué es | Nombres viejos (no usar) |
|---|---|---|
| **NEXO** | Marca madre. La plataforma que conecta productos, ventas y operación de pequeños negocios. Para el comprador, simplemente "NEXO". | Nexo agencia, NEXO Commerce, NEXO Busca, NEXO Marketplace (como marca) |
| **NEXO Business** | El sistema del negocio: caja (POS), inventario, panel, equipo, pedidos, sincronización. | Casa Viva Core (*solo cuando se refiere al software*), Ultra Ventas, NEXO Sync (como producto) |
| **NEXO Impulsa** | La oficina móvil de gestoras y vendedores: tienda propia, enlaces, comisiones. | Oficina de gestoras, Mi Tienda gestora |
| **Implementación NEXO** | El servicio humano que instala NEXO en cada comercio (diagnóstico, digitalización, configuración, capacitación). | Agencia Nexo, Rocket Social Media, Brand Lovers, Studio One |

Regla de marca: el nombre siempre es **NEXO** más una palabra que dice para quién es. No se crean marcas nuevas con "NEXO" delante sin pasar por `DECISIONES.md`.

## Piezas internas (solo para el equipo y los agentes)

- **Core**: la base común (Supabase `nexo-production`, esquema `nexo_business` y lo que se añada). Todo producto lee y escribe aquí.
- **Catálogo verificado**: producto o servicio con foto, precio, stock y estado de verificación. Es la unidad básica de NEXO.
- **Conocimiento**: información verificada (políticas, horarios, mensajería, FAQ) que usa el asistente.
- **Evento**: registro de algo que pasó (venta, pago, devolución). Nunca se borra.
